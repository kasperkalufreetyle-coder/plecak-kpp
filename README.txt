RescueOS 1.0 – instalacja na GitHub Pages

1. Utwórz NOWE publiczne repozytorium, np. RescueOS.
2. Prześlij WSZYSTKIE pliki z tego katalogu do katalogu głównego repozytorium (nie przesyłaj samego ZIP).
3. Settings > Pages > Build and deployment > Deploy from a branch > main > /(root) > Save.
4. Otwórz https://TWOJ_LOGIN.github.io/RescueOS/ w Safari.
5. Safari > Udostępnij > Do ekranu początkowego > Dodaj.

Dane są przechowywane lokalnie. Eksportuj regularnie plik JSON w Ustawieniach.
W pierwszej kolejności uzupełnij pojazdy i sprzęt lub dodaj przykładowy szablon.
Wersja szkoleniowa. Nie zastępuje dokumentacji i procedur jednostki.
